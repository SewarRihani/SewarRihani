<summary><b>🐾 CareTail Echo</b>: the vet labelling tool from my graduation project</summary>
<br>

<img src="assets/project-care.svg?v=2" width="100%" alt="CareTail Echo's labelling screen: a cat clip plays on a green oscilloscope and the vet presses Positive, Negative or Unknown.">

CareTail Echo hears a pet and tells you its species and emotion, using CNNs on Mel-spectrograms. To train it, I needed expert labels, so I built this tool for veterinarians. A vet listens to each of **1,201 cat and dog recordings** and labels it **Positive**, **Negative** or **Unknown**. Progress saves to a CSV, so a vet can stop and pick up later.

`Python` `Streamlit` `pandas` `1,201 clips`

**[Open the repo](https://github.com/SewarRihani/OnlineLabelingApp)**

<details>
<summary><b>🧹 OCDAgent</b>: keeps a Mac tidy, colour-coded, and never deletes on its own</summary>
<br>

<img src="assets/project-ocd.svg?v=2" width="100%" alt="OCDAgent sorting a Mac: colour-coded folders with emoji pop into place, and a stamp reads 93 moved, 0 deleted.">

OCDAgent sorts a messy Mac into colour-coded folders with an emoji on each one. It proves duplicates byte by byte (even inside zips) before anything goes, and every move can be undone. Each night it tidies the Desktop and Downloads. Anything that could be deleted goes into a *Check for deletion* folder, so the person decides, not the agent.

`Python (standard library only)` `launchd` `Finder tags`

🔒 Public version coming soon.
</details>

<details>
<summary><b>🍳 Chefmates</b>: a two-player pixel game about what an AI agent needs</summary>
<br>

<img src="assets/project-chef.svg?v=2" width="100%" alt="Chefmates: Salt and Pepper stand in a pixel kitchen next to a broken mixer. The parts bar shows Knowledge found, 1 of 4.">

Two players shrink into Salt and Pepper and search a giant kitchen for the four parts of a runaway mixer: its **goal**, **knowledge**, **tool** and **rules**. Fix it, and you've learned what an AI agent needs. It was made for a live booth, so it runs offline on one laptop.

`TypeScript` `React` `own canvas game engine` `Node + Express`

🔒 Code going public soon.
</details>
